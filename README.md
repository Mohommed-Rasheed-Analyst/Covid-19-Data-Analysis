# COVID-19 Data Analysis

## About the Project

This project is about analyzing COVID-19 data using Python and Pandas.

I worked with datasets containing confirmed cases, deaths and recoveries and explored how the numbers changed over time. I also compared different countries and regions to understand the trends in the data.

## What I Worked On

- Explored the COVID-19 datasets and their structure
- Analyzed confirmed cases over time
- Looked at the countries with the highest number of confirmed cases
- Analyzed COVID-19 trends in China
- Checked and handled missing values
- Found the highest daily increase in cases among Germany, France and Italy
- Compared recovery rates between Canada and Australia
- Analyzed death rates across Canadian provinces and territories
- Converted the deaths dataset from wide format to long format
- Analyzed total and average daily deaths by country
- Studied the change in total deaths in the United States
- Merged confirmed, deaths and recovery data
- Compared monthly COVID-19 trends for the US, Italy and Brazil
- Compared recovery and death numbers for South Africa
- Analyzed the monthly recovery ratio for the US

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses COVID-19 datasets containing confirmed cases, deaths and recoveries recorded over time.

The data contains country and province/state level information, which was cleaned and aggregated where required for the analysis.

The dataset file is not included in this repository and needs to be provided separately to run the notebook.

## Note

Some of the recovery data has reporting inconsistencies, especially for the US. These have been taken into account while interpreting the results.

The analysis is based on the reported data available in the dataset.
